# notes/

面談ごとの文字起こし・要約 md の正本置き場。

- フォルダは面談日付ごとに分ける（例：`2026-11-09/`）。ファイル名にも面談日付を含める（規則の正本は `../docs/状態管理.md`「セッション識別子」）。
- 自動生成分は「下書き（未照合）」として保存し、本人照合後に確定版へ更新する（下書き表記の正本は `../docs/状態管理.md`「下書き表記」）。
- 音声ファイルは絶対に置かない（正本は `../docs/状態管理.md`「音声ファイルの配置」）。
- 実ファイルは `.gitignore` 対象で、GitHub へは上がらない（追跡対象はこの README のみ）。保存時は保存ガードが、保存先が作業コピー内にあり ignore 済みであることを機械確認する（正本は `../docs/手順書.md`「保存ガード」）。
