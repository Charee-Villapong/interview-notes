# interview-notes

面談準備・振り返りノートの成果物リポジトリ。

- `notes/` — 面談ごとの文字起こし・要約 md の正本（面談日付ベースのフォルダ構成）。自動生成分は「下書き（未照合）」として保存し、本人照合後に確定版へ更新する（下書き表記の定義は `docs/状態管理.md`「下書き表記」を参照）。
- `pipeline/` — VM側パイプライン（状態管理・転送受信検証・保存ガード・削除ガード）の Python 実装とテスト。
- `mac-app/` — Mac側ツール（メニューバー常駐の録音アプリ）のソース。仕様と連携は `docs/P3計画.md`、ビルドと配置の手順は `docs/P3実働手順.md`、使い方は `mac-app/README.md`。
- `docs/` — 状態管理の正本、手順書、P3計画、P3実働手順。

## 絶対のルール

- 音声ファイルはこのリポジトリに置かない（正本は `docs/状態管理.md`「音声ファイルの配置」）。
- 保存処理はコード側で音声・動画拡張子を自動確認し、1件でも含まれていれば保存を中止する（`pipeline` の保存ガード。対象拡張子の正本は `docs/状態管理.md`「保存ガードの拡張子リスト」）。
- 認証情報・接続情報・個人を特定する値はコードや文書に書かない。環境依存値は環境変数またはローカル設定（gitignore 済み）から読む。

## パイプラインの使い方（VM側）

環境変数でデータ領域を指定する（定義の正本は `docs/状態管理.md`「データ領域と環境変数」）。

- `INTERVIEW_DATA_DIR` — 状態・音声受信・ステージングを置くデータ領域のルート
- `INTERVIEW_NOTES_DIR` — md 保存先（このリポジトリの `notes/` へのパス）

詳細は `docs/手順書.md` と `docs/状態管理.md` を参照。
