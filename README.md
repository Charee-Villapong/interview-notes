# interview-notes

面談準備・振り返りノート企画（AI組織 Issue #11）の成果物リポジトリ。

- `notes/` — 面談ごとの文字起こし・要約 md の正本（面談日付ベースのフォルダ構成）。自動生成分は「下書き（未照合）」として保存し、本人照合後に確定版へ更新する。
- `pipeline/` — VM側パイプライン（状態管理・転送受信検証・保存ガード・削除ガード）の Python 実装とテスト。
- `docs/` — 状態管理の正本、手順書、開発ノート。

## 絶対のルール

- 音声ファイルはこのリポジトリに置かない。音声は Mac（原音声）と VM（処理用の一時コピー）にのみ置く。
- 保存処理はコード側で音声・動画拡張子を自動確認し、1件でも含まれていれば保存を中止する（`pipeline` の保存ガード）。
- 認証情報・接続情報・個人を特定する値はコードや文書に書かない。環境依存値は環境変数またはローカル設定（gitignore 済み）から読む。

## パイプラインの使い方（VM側）

環境変数でデータ領域を指定する（既定値はコード側の相対既定ではなく、必ず環境変数か設定で与える）。

- `INTERVIEW_DATA_DIR` — 状態・音声受信・ステージングを置くデータ領域のルート
- `INTERVIEW_NOTES_DIR` — md 保存先（このリポジトリの `notes/` へのパス）

詳細は `docs/手順書.md` と `docs/状態管理.md` を参照。
